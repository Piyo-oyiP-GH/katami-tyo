# かたみ帳 の仕様（現在の版）

実装に合わせた、いまの仕様です。動かし方・環境変数は [src/README.md](../src/README.md)、サーバと画面の担当の境目・API は [src/CONTRACT.md](../src/CONTRACT.md)、画面の作りは [src/web/README.md](../src/web/README.md) にあります。ここでは重ねて書きません。

## 1. 誰のための何か

片付けの現場で物を撮ると、その場にいない親族も、捨てる前に「待った」をかけられるアプリです。

- 撮る人：現場にいる親族。物を 1 つずつ撮り、「残したい／迷う／処分したい」のどれかを選ぶだけ
- 見る人：離れた親族。物の写真と、読めた文字、物どうしのつながりを見て、残してほしい物に「待った」を押す。**1 人でも押せば、その物は残す**
- 故人や本人のことを深く知らない人でも、判断の材料を持てることが狙いです

捨てるか残すかを決めるのは家族です。かたみ帳 は決めません。材料を並べ、見落としに気づけるようにします。

## 2. 画面

画面は React 製で、`/app/` で開きます（`src/web/`）。以前の素の HTML の画面は `/` に残っています。切り替えは `#` の後ろに置き、招待のトークンをサーバのログに残しません。

| 画面 | 伝えること |
|---|---|
| 入口 | 見本で試す／招待で入る／新しい片付けを始める |
| つながり（最初の画面） | あなたに関係しそうな物と、物どうしのつながりが、開かずに分かる。写真の格子。写真をまたぐ「気づき N 件」は閉じて置く。写真ごとの知らせは写真の左上の札 |
| 物の詳細 | Claude が見つけた一言と、読めた文字、つながる物、分かったこと（出どころ付き）、行き先、待ったをかけた人。待ったは下に固定 |
| 撮る | 撮ったら 3 択で仕分けるだけ。5 秒は取り消せる。送れなかった写真は端末に残し、後で送り直す |
| 探す | 読めた文字や見立てから探す。どの出どころで一致したかを出す |
| 人 | 参加者と招待。写真の文字から見えてきた人の札 |
| 仕分け先 | 先に置き場を決めるやり方（任意）。端末にだけ残り、他の人とは共有されない |
| 捨てる前の確認 | 「処分したい」の物のうち、待ったの付いた物を示す。袋から抜く印は端末にだけ残る |

画面の言葉は「残したい／迷う／処分したい」です。API の値は `keep`／`unsure`／`drop` です。

## 3. 物の記録

写真 1 枚が 1 つの記録（モノカード）になります。記録は次の 4 つを混ぜずに持ち、出どころを画面に出します。

| 区分 | 中身 | 作るところ |
|---|---|---|
| 読めた文字 | 写真の中の字。手書きか、人名・日付・数字かの種類付き。読めない所は〔不明〕のまま | Claude が読む。確からしさはコードで付ける |
| 見えた物 | 物の種類、見えた根拠、手書き・宛名や署名・紙焼きの原本・古びといった印 | Claude が観察する |
| 見立て | 「〜かもしれません」の形の推測。事実とは限らない | Claude。文字の裏付けが無い固有名詞や年は、見立てに下げる |
| 家族の言葉 | 訂正（「違う」ボタン）、人物の札への書き足し、待ったのひとこと | 家族。読み取りより優先し、写真の根拠の数には入れない |

読み取りは写真 1 枚につき 4 回、並列で呼びます。

1. 文字読み：全文字を読む
2. 再読：1 の結果を見せずに、人名・日付・数字だけ読み直す
3. 観察：種類、根拠、類義語、見立て
4. 対象と背景：写真の主役と背景に写った物を分け、写真ごとの知らせ（下の「背景の見落とし」）を作る。失敗しても全体は止めない

文字を読む処理と分類を分けるのは、一緒にすると読める量が大きく減ったためです。

**確からしさ**は「はっきり／一部あやしい／読みにくい」の 3 段階で、`min(本人申告, 文字読みと再読の一致, 画像の上限)` をコードで計算します。同じモデルの再読なので「確認済み」とは書きません。画像の上限は端末で測ったぼけと白飛びで、下げる方向にだけ使います。

**手がかりの多い順**：一覧は、手書き 3＋人名 3×c＋日付 2×c＋宛名や署名 2＋紙焼きの原本 2＋古び 1 の点数で並べます（c は確からしさで 1／0.7／0.4）。各項は有る無しで数えます。大切さの順ではなく、画面にもそう注記します。理由を平文 1 行で添え、下位も全件見せます。読めない手書きは点を残し、「撮り直し候補」にします。ぼけた手紙が下に埋もれないためです。

**失敗しても消さない**：読み取りに失敗した写真は一覧に残し、「もう一度読む」で読み直せます。

## 4. 待った・人カード・招待・確認

**待った**：物ごとに、押す、ひとこと、取り下げができます。「残す」という状態は保存せず、取り下げられていない待ったが 1 つでもあれば残す、と数えます。誰が押したかも残ります。

**人カード**：写真から見えてきた人を、1 人 1 枚の札にまとめます。札には読めた名前と、持ち主の傾向などの仮説が付きます。

- 仮説の強さは、つながる物の数でコードが決めます：1〜2 個は弱、3〜9 個は中、10 個以上は強め。数えるのは「はっきり」の読みと、見えた物（字の無い物を含む）だけ。読みにくい物と家族の書き込みは数えません
- 札から物の番号へ、根拠として飛べます。番号の実在はコードで確かめます
- 5 枚ごとか 60 秒で、いまの札と新しい写真だけを使って差分更新します（全写真を送り直しません）。更新は同時に 1 つ
- 参加者の札（丸）と、写真から見えてきた人の札（四角）は別物です。名前が同じでも自動では結びません。結びは人が確かめて決めます
- 健康・お金・人間関係の仮説は作りません。顔で人を見分けません

**招待**：片付けを始めた人が相手の名前を入れて招待を発行し、リンクを送ります。相手は開くだけで参加し、以後は名前の入力なしで待ったに名前が付きます。

- トークンは 128 ビット以上の乱数で、保存するのはハッシュだけ。止めると、そのリンクで入った端末の入室も無効になります
- 招待で入った端末は、その片付けにだけ入れます。使い切りで、別の人のリンクを開いても今の人は変わりません
- 戻れる道は「自分用のリンク」だけです（Cookie が消えたとき用）
- 写真は公開 URL を持たず、Worker を通して参加者にだけ返します。すべての API で参加者かを確かめます

**捨てる前の確認**：「処分したい」の物のうち待ったの付いた物を、誰が待ったかと一緒に出します。ここで抜いてから捨てます。

## 5. 気づき

**背景の見落としの知らせ**：写真の主役ではなく背景に、読めそうな文字や気になる物が写っているとき、写真ごとに 1 行の問いかけを出します（詳細の「気づき」、つながりの写真の札）。線と知らせは、根拠の文がその物の「見えたこと」に本当にあるかをコードで確かめ、無ければ外します。

**箱ぜんたいの気づき**：複数の写真をまたぐ知らせです（「気づき N 件」）。人物の更新の入口で、`claude-opus-5-5` が文だけを材料に 1 箱 1 回作ります。

**記憶係**：任意の機能です。片付け 1 つにメモリストア 1 つを持ち、日をまたいで背景の手がかりを覚えます（Managed Agents）。新しく読み終えた物の「対象と背景」の文だけを渡し、写真は渡しません。知らせは回ごとに足し、新しい順に 6 つまで。失敗したら 1 回の呼び出しに戻り、片付けを消すときはメモリストアも消します。設定が無ければ使いません。

## 6. AI に判断させない約束

- Claude は観察だけを返します。「大切」「貴重」「捨ててよい」「残すべき」などの判断、勧め、価値づけを言いません
- 順位、確からしさ、仮説の強さは、コードで計算します。Claude の自己申告を使いません
- コードが出力を見張ります。判断の語と言い換えを見つけたら作り直し、残れば消します。健康・お金・人間関係の見立ても消します。文字の裏付けが無い固有名詞や年は、見立てに下げます
- 読めない文字を推測で補いません。写真の中の文字は命令として扱いません
- 画面は「読めた」「見えた」「Claude の見立て」「家族が書いた」を分け、写真と並べて出します

## 7. 料金と悪用の守り

上限は、写真を置く前・キューに積む前に確かめ、超えたら 429 を返します（端末の写真は消えません）。

- 読み取り枚数の上限：片付け 1 つ・接続元・全体の 1 日ごと、見本は 1 つあたり
- 見本と片付けを作れる数の、接続元ごと・全体の 1 日の上限
- 人物の更新の回数の上限
- 止めるスイッチ：一つの設定で Claude の呼び出しを全部止められます（503）
- 見本は 24 時間で、物も写真も消えます。定期処理が D1 と R2 を掃除し、読み取りのまま止まった物を積み直します
- 見本は架空のデータの複製で、本物とは混ざりません。見本の中で撮ると実際に Claude を呼ぶので、画面に注意を出します

値と環境変数は [src/README.md](../src/README.md) の表にあります。

## 8. わざと作っていないもの

動画からの読み取り、自動撮影、現場の音声、場所の記録、部屋の 3D、業者が撮る形、OAuth のログイン、ゲストの継続（見本は 24 時間で消える）。置き場と「抜いた」印を、親族と共有することも作っていません。
