# YukariNote（実装）

旧名は「待った箱」です。コードの中の名前（matta など）に残っています。

片付けの現場で物を撮ると、その場にいない親族も、捨てる前に「待った」をかけられるアプリです。

親族のことを深く知らない人でも、判断の材料を持てるようにします。

## 何ができるか

1. 段ボールの中身を 1 つずつ撮ります。撮るときに「いる／いらない／迷う」のボタンを押します。
2. Claude が写真を読み、モノカードを作ります。読めた文字、見えた物、Claude の見立てを分けて出します。
3. 一覧は手がかりの多い順に並びます。大切さの順ではありません。
4. 親族が検索し、詳細を見て「待った」を押します。1 人でも押せば残します。

Claude は「大切です」「捨ててよい」とは言いません。観察だけを返します。順位と確からしさはコードで計算します。

## 動かす

要るもの：Node.js 24、Claude の API キー。Cloudflare のログインは要りません。すべて手元の PC で動きます。

```bash
git clone <このリポジトリ>
cd <リポジトリ>/src
npm ci
cp .dev.vars.example .dev.vars
```

`.dev.vars` を開いて、2 つの値を入れます。

- `ANTHROPIC_API_KEY`：自分の API キー
- `SESSION_SECRET`：長い乱数。次のコマンドで作れます

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

`.dev.vars` は Git に入りません。人に渡さないでください。

次に、データの置き場所を決めて起動します。写真がリポジトリに残らないよう、置き場所はリポジトリの外にします。

```bash
export MATTA_STATE_DIR="$HOME/matta-box-state"   # PowerShell は $env:MATTA_STATE_DIR = "$HOME\matta-box-state"
npm run db:migrate
npm run dev
```

ブラウザで http://localhost:8791 を開きます。`MATTA_STATE_DIR` を決めないと、クローンした場所の 1 つ上に `.matta-state` フォルダを作って使います。`db:migrate` と `dev` は同じ置き場所で動かしてください。

## まず見本で試す

入口の「見本で試す」を押します。

- 架空の家族の 12 点の物、人物の札、参加者、待ったが入っています
- ログインは要りません。Claude も呼びません。料金はかかりません
- 人ごとに別の片付けとして複製します。本物のデータとは混ざりません
- 24 時間を過ぎると、物も写真も消えます

名前も物も画像も作りごとです。データは `src/sample/data.ts`、画像は `public/sample/` にあります。画像は `node src/sample/make-images.mjs` で作り直せます。

見本の中で撮ると、本物の Claude を呼びます。写真 1 枚につき 4 回呼ぶので料金がかかります。「違う」で文字を直したときも、人物の更新で呼びます。見本の中で読めるのは 10 枚までです。画面にも注意を出します。

## 自分の物で試す

1. 入口の「新しい片付けを始める」を開き、自分の名前と片付けの名前を入れて「始める」を押します。
2. 「撮る」の画面で物を撮ります。写真 1 枚ごとに Claude を呼びます。
3. 「人」の画面で、相手の名前を入れて招待を発行し、リンクを送ります。相手は開くだけで参加します。

撮った写真は自分の PC に残ります。他の人に見せたくない物は撮らないでください。

## 同じ Wi-Fi のスマホで試す

1. PC とスマホを同じ Wi-Fi につなぎます。
2. PC で、外から入れる形で起動します。

   ```bash
   npm run dev -- --ip 0.0.0.0
   ```

3. Windows のファイアウォールが許可を聞いてきたら、プライベートネットワークだけ許可します。
4. PC の IP アドレスを調べます。Windows は `ipconfig`、Mac は `ipconfig getifaddr en0` です。
5. スマホのブラウザで `http://<PC の IP アドレス>:8791` を開きます。

この形は https ではありません。ブラウザの決まりで、画面の中のカメラは使えません。ボタンを押すとスマホの標準のカメラが開き、撮ると押した山に入ります。画面の中のカメラを使うには、https で開く必要があります（トンネルか配備）。

同じ Wi-Fi の人なら誰でも開ける状態です。下の「守り」の上限が料金の歯止めになります。試し終わったら止めてください。

招待のリンクは、開いている住所のまま作られます。localhost で発行したリンクはスマホで開けません。PC でも `http://<PC の IP アドレス>:8791` を開いて、片付けを作り、招待を発行してください。localhost で作った片付けは、この住所では開けません。入る状態が住所ごとに分かれるためです。

## わざと作っていないもの

- 動画からの読み取り
- 自動撮影
- 現場の音声
- 場所の記録
- 部屋の 3D
- 業者が撮る形
- OAuth のログイン（本番で足します）
- ゲストの継続（見本は 24 時間で消えます）

## ログインについて

**本番にはログインが必須です。**

今の版は、試しやすさのためにログイン画面を持ちません。人ごとの招待リンクと署名 Cookie で動きます。

- 招待のリンクを持つ人は、その片付けの中でだけ、招待された人として入れます。その人の別の片付けには入れません
- すでに名前のある人が招待を開くと、その招待は使い切りになります。リンクでは入り直せません
- 別の人のリンクを開いても、今の端末の人は変わりません
- 失効すると、リンクで入ったセッションも消えます

ログインが無いので、端末の記録（Cookie）が消えると戻れません。「人」の画面の「自分用のリンク」を作って保存してください。作成者が戻る道はこれだけです。セッションは使っている間は延びます。

家族の写真と名前を扱うので、本番では Google と LINE のログインを招待に結び付けます。リンクだけで入れる形のままでは公開しません。結び付け先の表（`identities`）は用意してあります。

## 守り

料金の暴走を止めるための決まりです。上限は写真を置く前、キューに積む前に確かめ、超えたら 429 を返します。端末の写真は消えません。

| 環境変数 | 既定 | 中身 |
|---|---|---|
| `READING_OFF` | なし | `1` で Claude の呼び出しを全部止めます。新しい写真と読み直しは 503 です |
| `PROJECT_DAILY` | 300 | 片付け 1 つの、1 日の読み取り枚数 |
| `SAMPLE_PHOTOS` | 10 | 見本 1 つで読める枚数 |
| `IP_DAILY` | 300 | 同じ接続元からの、1 日の読み取り枚数 |
| `SAMPLE_IP_DAILY` | 20 | 同じ接続元が見本の中で読める、1 日の枚数 |
| `TOTAL_DAILY` | 500 | 全体の 1 日の読み取り枚数 |
| `GUEST_IP_DAILY` | 10 | 同じ接続元が作れる、1 日の見本の数 |
| `GUEST_TOTAL_DAILY` | 100 | 全体で作れる、1 日の見本の数 |
| `PROJECT_IP_DAILY` | 20 | 同じ接続元が作れる、1 日の片付けの数 |
| `PERSONS_DAILY` | 100 | 片付け 1 つの、1 日の人物の更新の回数 |
| `SAMPLE_PERSONS` | 10 | 見本 1 つの、人物の更新の回数 |

`.dev.vars` に書くと変えられます。

期限切れの見本は、定期処理が D1 の行と R2 の写真を消します。配備では 1 時間ごとの cron で動きます。手元の `wrangler dev` では cron が動かないので、画面を開いたときに動きます（1 分に 1 回まで）。同じ処理が、読み取りのまま 3 分止まった物をキューに入れ直します。

## 作りの概要

- TypeScript、Hono、Cloudflare Workers、D1、R2、Queues
- 画面は React（`src/web`、Vite でビルドして `/app/` から出す）です。素の HTML の前の版も `/?legacy` に残しています
- 読み取りは 1 枚につき 4 回、並列です。文字読み、再読、観察、対象と背景を `claude-sonnet-5-5` で呼びます（箱ぜんたいの知らせと記憶係は `claude-opus-5-5`）
- 写真は公開 URL を持たず、Worker を通して参加者だけに返します

詳しい決まりは `CONTRACT.md` にあります。

## 確かめる

```bash
npm run typecheck
npx playwright install chromium
node scripts/app/ui-test.mjs --out <リポジトリの外のフォルダ>
node scripts/app/fix-test.mjs --out <リポジトリの外のフォルダ>
```

計算だけの試験は `scripts/ai/unit.test.ts` と `scripts/ai/persons.test.ts` です。動かし方は各ファイルの頭に書いてあります。

見本の画像を印刷して撮り直すと、合成の画像に近い物は画像の上限に当たり、「一部あやしい」止まりになることがあります（960x720 の合成画像で確かめた結果です）。上限に当たると「はっきり」の数が増えないので、人物の強さも付きません。実機の写真で同じかは、まだ確かめていません。

画面の試験は、スマホの大きさのブラウザで動きます。Claude は置き換えのサーバを使うので、料金はかかりません。
