# React 版の画面（YukariNote、仮の名前）

今の画面（`../public` の素の HTML）を消さずに、別の場所で作り直した画面です。API とデータ（`../src` の Hono、D1、R2、Queues）は変えていません。今の API（`../CONTRACT.md`、`../src/routes/`）だけを使います。

## 動かす

API のサーバ（`npm run dev`、8791 番）を先に動かします。手順は `../README.md`。

```bash
cd src/web
npm ci
npm run dev        # http://localhost:5173/app/ 。/api は 127.0.0.1:8791 へ流す
```

Workers の静的配信で出すときは、ビルドします。結果は `../public/app/` に出て、`/app/` で開けます。今の画面は `/` のままです。

```bash
npm run build      # 型の確認と、../public/app への出力
```

- `public/app/` はビルドの結果なので Git に入れていません。配備の前に必ず `npm run build` します
- `wrangler.jsonc` と `../package.json` は共有のファイルなので変えていません。`assets.directory` が `./public` なので、`public/app` に置くだけで出せます
- 画面の切り替えは `#` の後ろに置きます（招待のトークンをサーバのログに残さないため。今の画面と同じ）

## 画面

| 画面 | パス | 伝えること |
|---|---|---|
| 入口 | `#/` | 見本で試す、招待で入る、新しく始める |
| つながり | `#/p/:pid` | あなたに関係しそうな物と、物どうしのつながりが、開かずに分かる。気づき（写真をまたぐ知らせ）は閉じた「気づき N 件」、写真ごとの知らせは写真の左上の札 |
| 物の詳細 | `#/p/:pid/item/:iid` | AI が見つけた一言と、ほかの物とのつながり。写真ごとの気づきは一言の下に1行。残してほしければ待った |
| 撮る | `#/p/:pid/capture` | 撮ったら、残したい／迷う／処分したいを選ぶだけ |
| 探す | `#/p/:pid/search` | 読めた文字や見立てから探す |
| 人 | `#/p/:pid/people` | 参加者と招待、物から見えてきた人 |
| 仕分け先 | `#/p/:pid/places` | 先に置き場を決めるやり方（任意） |
| 捨てる前の確認 | `#/p/:pid/check` | 処分したい物から、待ったの物を抜く |

判断の言葉は画面だけ「残したい／迷う／処分したい」にし、API の値は `keep`／`unsure`／`drop` のままです。

## API に無くて、画面だけで持っているもの

- **置き場（仕分け先）**：API に無いので、端末の localStorage にだけ残します。親族とは共有されず、撮った物にも結び付きません
- **捨てる前の確認の「抜いた」印**：同じく端末にだけ残します
- **招待のリンク**：サーバは今の画面の形（`/#/join/…`）で返します。React 版では `/app/#/join/…` に直して見せます

## 決まり

文字は 28/18/16px の 3 段階、角丸は 0・8px・円の 3 種類、箱の入れ子なし、茜は待っただけ、動きは操作への応答だけで `prefers-reduced-motion` に従います。配色は昼が案A、OS が暗い設定のときは案C。書体は BIZ UDPGothic、AI の一言と家族の言葉だけ BIZ UDPMincho。

## 写した部品

`src/lib/uploader.js` と `src/lib/image.js` は `../public/js/` から写しました（EXIF を外す、5MiB に収める、縮小画像、取り消しの 5 秒、送れなかった写真を IndexedDB に残す）。今の画面を消しても React 版が動くよう、別に持っています。
